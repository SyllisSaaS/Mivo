# Custom Project Safety

Mivo offers custom web development — but **every custom request must be assessed before you accept it**.

The goal is not to say "no" forever. The goal is to avoid promising work before you've confirmed implementation, timeline and complexity.

## The rule

> If you haven't built something similar before, classify it YELLOW or RED until you've investigated. Never commit on the website or in a quote until you're confident.

## Straightforward work (usually GREEN)

These are within reach for early-stage development:

- Marketing websites and landing pages
- Multi-page business sites
- Portfolio and showcase sites
- Responsive layouts and mobile-first design
- Contact forms and enquiry flows
- Image galleries and lightboxes
- Social media links and embeds
- Google Maps embeds
- Third-party booking widgets (Calendly, Acuity, etc.)
- Simple CMS-free content sites
- Website redesigns (visual + structural)
- Basic SEO setup (titles, descriptions, semantic HTML)

## Work that needs investigation (YELLOW)

Possible, but research first:

- E-commerce via Shopify, Squarespace Commerce, or similar platforms
- Multi-language sites
- Blog with many posts (content migration)
- Custom animations with performance requirements
- Multiple third-party integrations
- Client-managed content (without building a full CMS)
- Booking beyond simple embeds

**Before quoting:** identify the platform/tool, read its docs, estimate honestly.

## Complex work (usually RED for now)

Do not promise these without significant experience:

- User registration and login systems
- Client portals with authentication
- Admin dashboards
- Subscription billing
- Custom payment processing (beyond platform defaults)
- Custom booking platforms (built from scratch)
- Large databases and complex data relationships
- REST/GraphQL API development
- SaaS applications
- Real-time features (chat, live updates)
- Mobile apps

**Response template:**

> "That's a bigger build than I can take on right now at the quality level you'd need. I'd rather be honest upfront than deliver something below standard. I can recommend [alternative / specialist] if helpful."

## Website messaging

The Mivo site should:

- Communicate custom development capability
- Emphasise honest scoping ("assessed individually")
- Not claim "we build anything"
- Include the process section so clients trust the approach

## When in doubt

1. Classify YELLOW
2. Spend 30–60 minutes researching
3. Re-classify GREEN or RED
4. Quote only if GREEN (or YELLOW with clear caveats)
