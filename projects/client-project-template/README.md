# Client Project Template

Duplicate this entire folder when starting a new client project.

Rename the copy to something clear, e.g. `projects/acme-coffee/`.

## Folder guide

| Folder / file | Purpose |
|---------------|---------|
| `project-info.md` | Client details, timeline, status |
| `requirements.md` | Scope, pages, features, constraints |
| `assets/` | Client logos, images, fonts, documents |
| `design-references/` | Inspiration, mockups, wireframes |
| `development/` | Notes, decisions, technical details |
| `deployment/` | Hosting, domain, DNS, deploy steps |
| `client-feedback/` | Feedback from client reviews |
| `revisions/` | Revision rounds and what changed |
| `launch/` | Launch checklist and go-live notes |
| `maintenance/` | Post-launch support and updates |

## Getting started

1. Copy this template folder
2. Open `project-info.md` and fill in the basics
3. Complete `requirements.md` before quoting
4. Follow `docs/business/client-process.md`
